# Evalyst

Evalyst is an assessment app built for programming courses, but usable for any quiz or assignment. Instructors build question banks, run timed quizzes, and grade GitHub assignments, with AI handling the parts that need judgement and an instructor reviewing anything the AI isn't sure about.

I built it for my own use, to assess students in a Laravel and Web Development course I taught as Guest Faculty at an engineering college. It's shared as-is in case it's useful to someone else.

Nothing in it is tied to Laravel, though. It works for a course in any programming language, and the quizzes work for any subject: choice questions and AI-graded written answers don't care what the topic is. Assignments can be any project kept in a public GitHub repository. Code questions get syntax highlighting and a code editor for Python, Java, C, C++, C#, Go, Rust, Ruby, Kotlin, Swift, JavaScript, TypeScript, PHP, SQL, HTML, CSS, Bash and JSON. Any other language is shown as plain text, and AI grading still works. The AI prompts work out the language and framework from the course and the question, so nothing assumes PHP or Laravel. To add a language, add it to `app/Enums/CodeLanguage.php` and register its highlighter in `resources/js/components/code/CodeEditor.vue` (CodeMirror) and `resources/js/lib/markdown.ts` (highlight.js).

## Features

- **Courses.** Every instructor in a course has the same access. Instructor accounts are invite-only.
- **Question banks.** Single choice, multiple choice, open text and code questions, written by hand or generated by AI from a topic. A second AI pass checks the answer keys, and you pick which drafts go into the bank.
- **Timed quizzes.** Choice questions are graded automatically. Open text and code answers are graded by AI against a rubric. The timer and deadlines are enforced on the server, and every student gets the full duration.
- **GitHub assignments.** Students submit a public repository URL, and it's graded at the submitted commit against automated checks and AI rules. Assignments support late policies and per-student deadline overrides. Repositories are read through the GitHub API and never cloned.
- **No student accounts.** Students join with an access code, either one per student from a roster or one shared code.
- **Live monitor.** See who is working, who has submitted, and live scores during a quiz. You can also let a student resume, reset an attempt, or force-submit it.
- **Review before publishing.** AI grades that are invalid or low-confidence go to a review inbox instead of reaching students.
- **Results and exports.** Release results by hand or automatically, use the gradebook, and export to CSV.
- **Cost tracking.** Every AI call is logged with its tokens and cost.

## Tech stack

- Laravel 13, Inertia v3, Vue 3, Tailwind CSS 4
- [Laravel AI SDK](https://github.com/laravel/ai) for AI agents with structured output. The default is OpenAI, and other providers the SDK supports can be configured.
- Laravel Fortify for authentication (2FA and passkeys included)
- MySQL and database queues
- Pest for tests

## Requirements

- PHP 8.5+ and Composer
- Node.js and npm
- MySQL
- An API key for an AI provider (OpenAI by default)
- A GitHub personal access token, for assignment grading. It only needs read access to public repositories and exists mainly to raise the API rate limit.

## Installation

```bash
git clone https://github.com/abbasali/evalyst.git
cd evalyst
composer setup
```

`composer setup` installs the PHP and JS dependencies, creates `.env`, generates the app key, runs the migrations and builds the frontend.

Then edit `.env`:

```dotenv
DB_DATABASE=evalyst
DB_USERNAME=root
DB_PASSWORD=

EVALYST_AI_PROVIDER=openai
EVALYST_AI_MODEL=gpt-5.4-mini
OPENAI_API_KEY=sk-...

GITHUB_TOKEN=ghp_...
```

If you changed the database settings, run the migrations again:

```bash
php artisan migrate
```

Create the first instructor, optionally with a first course. Other instructors are invited from inside the app.

```bash
php artisan evalyst:make-instructor you@example.com --name="Your Name" --course="Laravel 101"
```

## Running it

```bash
composer dev
```

This starts the web server, Vite, the log viewer and a queue worker for the `ai` and `default` queues. AI generation and grading only run in queued jobs, so the worker has to be running.

Also run the scheduler in a second terminal. It auto-submits quiz attempts when a student's time runs out (for example, if they closed the browser) and retries stuck grading jobs:

```bash
php artisan schedule:work
```

In production, run a queue worker for `ai,default` and the scheduler (`php artisan schedule:run` every minute).

## Basic usage

**Quizzes**

1. Sign in and pick a course, or create one.
2. Add questions to the bank, by hand or with **Generate with AI**. You choose which generated drafts to keep.
3. Create a quiz. Set when it opens and closes, the duration, and the questions with their marks. The closing time is the last moment a student can start.
4. Choose how students join: a roster, where each student gets their own code, or a single shared code.
5. Students open `/join` and enter their code. Watch progress on the quiz's **Monitor** tab.
6. Open answers are graded by AI after submission. Anything the AI flags or isn't confident about goes to the **Review** inbox.
7. Release results by hand, or let them release automatically after the quiz closes and the last attempt finishes. Students see their results through the link on their completion page.

**Assignments**

1. Create an assignment with a deadline, a late policy and grading rules (automated checks and AI rules, each worth a number of marks).
2. Students join with their code and submit a public GitHub repository URL.
3. Each submission is graded at its commit. Review flagged results, then release.

## Testing

```bash
composer test
```

This runs Pint, the TypeScript type check and the Pest suite. Tests never hit the network: AI calls use the SDK's fakes, and GitHub calls use recorded fixtures in `tests/Fixtures/github/`.
